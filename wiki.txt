'''Colegio San Caio - Book Software Manual''' (ISBN '''978-3-00-068463-0''') is an open educational resource providing software manual and livebook material.

== Overview ==
The project is hosted on GitHub under organization [[Colegio-San-Caio]] and published via GitHub Pages as a TeX Gist.

* TeX source: [https://colegio-san-caio.github.io/demo-repository/main.tex main.tex]
* HTML view: [https://colegio-san-caio.github.io/demo-repository/tex.html TeX Gist Viewer]
* PDF: [https://colegio-san-caio.github.io/demo-repository/book.pdf book.pdf]
* Cover: [https://colegio-san-caio.github.io/demo-repository/cover.jpg cover.jpg]

== Content ==
Content is authored in LaTeX (''main.tex'') and rendered to:
* PDF via LaTeX
* HTML via KaTeX
* MediaWiki via pandoc: <code>pandoc main.tex -t mediawiki</code>
